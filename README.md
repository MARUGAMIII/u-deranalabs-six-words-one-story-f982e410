A complete story in exactly six words. A man dies, his obituary is
published — and it names two different wives. One line, a whole double
life implied: did either wife know about the other, and which one wrote
the obituary?

The entry — **6 words, 40 characters**:

> The obituary listed two different wives.

## Run it

```sh
python3 main.py
```

This writes the story to `/output/entry.txt` (one line, UTF-8, exactly
six words, 40 characters including the final period).
